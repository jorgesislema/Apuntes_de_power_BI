# 2.2.3 Funciones de Texto y Fechas en DAX

## Introducción

Las funciones de texto y fechas permiten manipular cadenas de caracteres y valores de fecha/hora dentro de expresiones DAX.

## Funciones de Texto

### CONCATENATE

Une dos o más cadenas de texto.

```dax
-- Sintaxis
CONCATENATE(<texto1>, <texto2>)

-- Ejemplo: Nombre completo
Nombre Completo = 
CONCATENATE(Clientes[Nombre], " ", Clientes[Apellido])

-- Alternativa con &
Nombre Completo = Clientes[Nombre] & " " & Clientes[Apellido]
```

### FORMAT

Formatea un valor como texto según un formato especificado.

```dax
-- Sintaxis
FORMAT(<valor>, <formato>)

-- Ejemplo: Fecha en formato español
Fecha Formateada = FORMAT(Ventas[Fecha], "DD/MM/YYYY")

-- Ejemplo: Moneda
Monto Formateado = FORMAT(Ventas[MontoTotal], "#,##0.00 €")

-- Ejemplo: Porcentaje
Porcentaje = FORMAT([Margen], "0.0%")
```

### LEFT / RIGHT

Extrae caracteres desde la izquierda o derecha.

```dax
-- Sintaxis
LEFT(<texto>, <número de caracteres>)
RIGHT(<texto>, <número de caracteres>)

-- Ejemplo: Primeros 3 caracteres del código
Prefijo = LEFT(Productos[Codigo], 3)

-- Ejemplo: Últimos 2 caracteres
Sufijo = RIGHT(Productos[Codigo], 2)
```

### MID

Extrae una porción de texto desde una posición específica.

```dax
-- Sintaxis
MID(<texto>, <posición inicial>, <longitud>)

-- Ejemplo: Extraer código de producto (posiciones 5-8)
Codigo Limpio = MID(Productos[Codigo], 5, 4)
```

### LEN

Devuelve la longitud de una cadena de texto.

```dax
-- Sintaxis
LEN(<texto>)

-- Ejemplo: Longitud del nombre
Longitud Nombre = LEN(Clientes[Nombre])
```

### UPPER / LOWER / PROPER

Convierte texto a mayúsculas, minúsculas o Title Case.

```dax
-- Sintaxis
UPPER(<texto>)     -- MAYÚSCULAS
LOWER(<texto>)     -- minúsculas
PROPER(<texto>)    -- Texto Con Mayúsculas Iniciales

-- Ejemplo: Nombre normalizado
Nombre Normal = PROPER(TRIM(Clientes[Nombre]))
```

### TRIM

Elimina espacios en blanco al inicio y final.

```dax
-- Sintaxis
TRIM(<texto>)

-- Ejemplo: Limpiar espacios
Nombre Limpio = TRIM(Clientes[Nombre])
```

## Funciones de Fechas

### YEAR / MONTH / DAY

Extraen componentes de una fecha.

```dax
-- Sintaxis
YEAR(<fecha>)
MONTH(<fecha>)
DAY(<fecha>)

-- Ejemplo: Componentes de fecha
Año = YEAR(Ventas[Fecha])
Mes = MONTH(Ventas[Fecha])
Día = DAY(Ventas[Fecha])
```

### DATE

Crea una fecha a partir de año, mes y día.

```dax
-- Sintaxis
DATE(<año>, <mes>, <día>)

-- Ejemplo: Crear fecha
Fecha Creación = DATE(2024, 12, 25)
```

### DATEDIFF

Calcula la diferencia entre dos fechas.

```dax
-- Sintaxis
DATEDIFF(<fecha1>, <fecha2>, <período>)

-- Ejemplo: Días desde el registro
Días Como Cliente = 
DATEDIFF(Clientes[FechaRegistro], TODAY(), DAY)

-- Ejemplo: Años de antigüedad
Antigüedad Años = 
DATEDIFF(Empleados[FechaIngreso], TODAY(), YEAR)
```

### TODAY / NOW

```dax
-- TODAY: Fecha actual sin hora
Fecha Actual = TODAY()

-- NOW: Fecha y hora actual
Fecha Hora Actual = NOW()
```

### WEEKDAY / WEEKNUM

```dax
-- WEEKDAY: Día de la semana (1=Domingo, 2=Lunes, etc.)
Día Semana = WEEKDAY(Ventas[Fecha], 2)  -- 2 = Lunes es 1

-- WEEKNUM: Número de semana del año
Semana = WEEKNUM(Ventas[Fecha], 2)  -- 2 = Lunes como primer día
```

## Ejemplos Prácticos

```dax
-- 1. Código de producto formateado
Codigo Formateado = 
"PRD-" & 
FORMAT(Productos[ProductoID], "0000") & "-" & 
LEFT(Productos[Categoria], 2)

-- Ejemplo resultado: "PRD-0001-EL" (Electrónica)

-- 2. Edad del cliente en años
Edad = 
DATEDIFF(Clientes[FechaNacimiento], TODAY(), YEAR)

-- 3. Trimestre en texto
Nombre Trimestre = 
"Q" & QUARTER(Ventas[Fecha]) & " " & YEAR(Ventas[Fecha])

-- Ejemplo resultado: "Q3 2024"

-- 4. Días hasta vencimiento
Días Hasta Vencimiento = 
DATEDIFF(TODAY(), Contratos[FechaFin], DAY)

-- 5. Clasificación por antigüedad
Clasificación Antigüedad = 
VAR Antigüedad = DATEDIFF(Clientes[FechaRegistro], TODAY(), YEAR)
RETURN
    SWITCH(
        TRUE(),
        Antigüedad < 1, "Nuevo",
        Antigüedad < 3, "Regular",
        Antigüedad < 5, "Fiel",
        "VIP"
    )
```

## Resumen de Funciones

| Categoría | Función | Descripción |
|-----------|---------|-------------|
| **Texto** | `CONCATENATE` | Une cadenas |
| | `FORMAT` | Formatea valores |
| | `LEFT/RIGHT` | Extrae desde extremos |
| | `MID` | Extrae porción media |
| | `LEN` | Longitud de cadena |
| | `UPPER/LOWER/PROPER` | Cambia caso |
| | `TRIM` | Elimina espacios |
| **Fechas** | `YEAR/MONTH/DAY` | Extrae componentes |
| | `DATE` | Crea fecha |
| | `DATEDIFF` | Diferencia entre fechas |
| | `TODAY/NOW` | Fecha/hora actual |
| | `WEEKDAY/WEEKNUM` | Semana del año |

## Errores Comunes

```dax
-- ❌ ERROR: Usar FORMAT para comparaciones
IF(FORMAT(Ventas[Fecha], "YYYY") = "2024", ...)

-- ✅ CORRECTO: Usar YEAR para comparaciones
IF(YEAR(Ventas[Fecha]) = 2024, ...)

-- ❌ ERROR: Olvidar que MONTH devuelve número
IF(Ventas[Mes] = "Enero", ...)  -- ¡ERROR!

-- ✅ CORRECTO: Comparar con número
IF(MONTH(Ventas[Fecha]) = 1, ...)
```
